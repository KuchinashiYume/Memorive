# Memorive v1.03

[Windows installer](https://github.com/KuchinashiYume/Memorive/releases/download/v1.03/Memorive-Setup-1.03-x64.exe) · [Complete portable package](https://github.com/KuchinashiYume/Memorive/releases/download/v1.03/Memorive-Portable-1.03-x64.zip) · [Test Console](https://github.com/KuchinashiYume/Memorive/releases/download/v1.03/Memorive-Test-Console-Setup-1.03-x64.exe)

## What's new

- **Read papers with an AI agent.** The new memo-research Skill lets agents such as Codex or Claude Code read papers for you. Papers an agent has already converted can go straight into Research Q&A, or you can hand the current question to an agent and get its cited answer back in the same conversation. The Skill also works on its own.
- **Test Console** now comes in English, Chinese and Japanese, with a review-and-results view and shareable summaries.
- Includes the settings-save fix from v1.02.01.

**Upgrading:** back up your data and settings, then upgrade with the installer or the complete portable package. The Test Console is installed separately; allow it in Memorive the first time it connects.

## v1.03 新内容

- **和 AI Agent 一起读文献**：新增 memo-research Skill。Codex、Claude Code 等 Agent 处理过的论文，可以直接加进研究问答；也可以把当前问题交给 Agent 去读，它带引用的回答会回到原来的对话。Skill 也能单独使用。
- **测试控制台**支持中、英、日三种语言，新增审核与结果页面，可以生成分享用的摘要。
- 包含 v1.02.01 的设置保存修复。

**升级方法**：先备份资料和设置，再用安装包或完整便携包升级。测试控制台需要单独安装，第一次连接时在 Memorive 里允许即可。

## v1.03 の新機能

- **AI エージェントと一緒に文献を読む**：memo-research Skill を追加しました。Codex や Claude Code などのエージェントが処理した論文を、研究 Q&A にそのまま追加できます。いまの質問をエージェントに渡すと、引用付きの回答が元の会話に戻ってきます。Skill は単体でも使えます。
- **テストコンソール**が日本語・英語・中国語に対応し、レビュー・結果画面と共有用の要約を追加しました。
- v1.02.01 の設定保存の修正を含みます。

**更新方法**：資料と設定をバックアップしてから、インストーラーまたは完全なポータブル版で更新してください。テストコンソールは別途インストールし、初回接続時に Memorive で許可してください。

## Research Skill

[memo-research Skill v0.2.0](https://github.com/KuchinashiYume/Memorive/releases/download/v1.03/Memorive-Research-Skill-0.2.0.zip) is also bundled with Memorive under `integrations/skills/memo-research`. Use it with an agent that supports local Skills. To convert PDFs when you use the Skill on its own, install the optional packages listed in `scripts/requirements-pdf.txt`.
