# Memorive v1.02

## 中文

这是发布前说明，尚不表示版本已经公开。最终文件以同一 Release 的程序、源码、校验清单与使用说明为准。

本版延续“读、理、证、存”的工作方式。研究问答增加主张支持与覆盖提示、轻量课题和知识更新、回答风格、分支重试和版本回看；长期未打开的问答可以归档，列表采用按需加载。文献的数值与逻辑核查分别保留范围、原文依据和人工意见，任务显示实际节点状态与耗时。

文献发现按研究方向寻找最新或高度相关的内容，保存题录、DOI、来源链接、可取得的摘要与推荐理由，并处理重复记录。全文由用户手动添加。首页提供研究入口和独立的 AI 近况。模型设置支持自定义 CLI；中文、英文、日文覆盖界面及之后生成的 memo 内容，原文献和历史版本不改写。解析改善结构、表格、页行定位和有限 OCR 的记录。

更新维护支持检查新版本、下载变化文件、完整包备用和明确的重启确认。旧 v1.01 首次使用同批更新助手；安装、更新及维护自有界面可切换三种语言。更新检查不等于自动安装，程序更新不应更换你的资料目录。

模型科研判断、OCR 和外部检索仍有漏检、误报、缺失或不可达的可能。首答失败和覆盖限制不能因工程测试通过而消失；对重要结论继续回看原文。CLI 的兼容性由实际协议和节点验证决定，并非支持所有命令行工具。公开元数据访问也属于网络请求。文献版权不因可检索而转移；题录不保证全文可取得。

项目代码由 OpenAI Codex 与 Anthropic Claude Code 生成、修改和迭代；项目发起者负责需求、产品设计与测试验收，未亲自编写代码。代码采用 AGPL-3.0-only，第三方组件保留各自许可。角色素材为非官方 AI 辅助二次创作，排除在代码许可之外；不存在 Nexon、Nexon Games 或 Yostar 的直接授权、关联、赞助或认可。

## English

These are pre-release notes, not a statement that this version is public. The application, corresponding source, checksum list and instructions must belong to the same final Release.

This version continues the read, organize, verify and retain workflow. Research Chat adds claim-support and coverage information, lightweight topics and knowledge updates, answer styles, retry branches and version history. Unopened conversations can be archived, and lists load their content on demand. Numeric and logical literature checks retain their scope, source evidence and user dispositions; tasks display actual node state and elapsed time.

Discovery uses research directions to find recent or highly relevant work, saves metadata, DOI, source links, available abstracts and recommendation reasons, and handles duplicates. Users add full text themselves. Home offers research shortcuts and a separate AI Updates report. Model settings support custom CLIs. Chinese, English and Japanese cover the interface and newly generated memo content, without rewriting original papers or saved versions. Parsing improves structural, table, page/line and bounded-OCR records.

Maintenance adds update checks, changed-file downloads, a full-package alternative and explicit restart confirmation. The original v1.01 uses the matching update helper for its first upgrade. The installer, updater and first-party maintenance screens support three languages. Checking does not authorize installation, and updating the application should not change your research-data location.

Scientific judgments, OCR and external retrieval can still miss, misread or fail to obtain information. Engineering checks do not erase first-response failures or coverage limits; revisit the original for important conclusions. CLI compatibility depends on its protocol and actual node validation, not merely an executable name. Public metadata access is network activity. Searchability transfers no paper rights and does not guarantee full-text access.

Project code is generated, modified and iterated with OpenAI Codex and Anthropic Claude Code. The initiator specifies requirements, designs the product and performs acceptance testing, and has not personally written the code. Code is under AGPL-3.0-only; third-party components retain their licenses. Character artwork is unofficial AI-assisted fan work excluded from the code license. ## 日本語

「読む・整える・確かめる・残す」の流れを引き継ぎます。研究問答には主張の裏付けとカバレッジの表示、軽量な研究課題と知識更新、回答スタイル、再試行の分岐、版の履歴を加えます。長く開いていない会話はアーカイブでき、一覧は内容を必要に応じて読み込みます。数値・論理分析は確認範囲、原文の根拠、利用者の判断を保持し、タスクは実際のノード状態と所要時間を示します。

研究方向に沿って最新または関連性の高い文献を探し、題録、DOI、出典リンク、取得できる抄録と推薦理由を保存して重複を処理します。全文は利用者が追加します。ホームには研究への入口と独立した AI 近況を用意します。モデル設定はカスタム CLI に対応します。画面と今後生成する memo の内容は中国語・英語・日本語に対応し、原文献と保存済みの版を改変しません。解析では構造、表、ページ・行位置、限定的な OCR の記録を改善します。

保守では更新確認、変更ファイルの取得、完全パッケージへの切り替え、明示的な再起動確認を扱います。従来の v1.01 からの最初の更新には同じリリースの更新ヘルパーを使います。インストーラー、更新、独自の保守画面は三言語に対応します。確認しただけでインストールは始まらず、アプリ更新によって研究データの場所を変えません。
