Memorive 网页会话只读桥接 v3.7

默认来源为 DeepSeek、Gemini、Kimi。Memorive「设置 → 对话精炼设置 → 网页会话库」可分别启停、替换三站。仅启用并已核实的模型官网参与读取和权限清单。

安装 / 更新
1. Memorive 准备组件后，在 Edge / Chrome 扩展管理页加载生成的扩展文件夹。
2. 修改站点配置后，重新加载该扩展；Memorive 核对版本和配置指纹后才允许读取。
3. 保持目标网站已登录。点击「测试读取」：每个启用来源最多读取 2 条。测试通过后才可完整同步；已有档案可增量同步，每站最多读取 10 条。
4. 扩展安装、浏览器启动只写本地身份回执，不会自行读取历史会话。扩展弹窗「测试读取」同样是每站 2 条，不是完整同步。
5. 下载的会话包由 Memorive 受管目录保存；自定义下载目录可手动导入。

自定义网站
- 选择「自定义 DOM」，配置已核实的官方聊天域名、会话路径和列表 / 用户 / 模型消息选择器。
- 初始官网目录覆盖 DeepSeek、Gemini、Kimi、Qwen、ChatGPT、Claude；按精确域名匹配，不接受同名网站、镜像站或任意子域名。其他官网须核实后加入目录。
- 目录来自软件内经核实的提供商官方资料；外部榜单、评分来源或自定义 JSON 不能扩展权限。官方身份核实不等于该站点读取规则已适配。
- 使用原有只读分页、正文滚动、完整性检查和去重通道。更换网址不等于网站自动兼容。
- 站点需要能从页面读取稳定会话地址和正文；Canvas、跨域 iframe、封闭 Shadow DOM 或结构无法区分角色的页面可能不支持。此时不生成完整同步资格，可用弹窗「录入当前界面」保留部分内容。
- 修改配置会使旧的试读资格失效；历史已导入会话不删除、不改成新站点。

边界
- 只读取用户已登录后可见的网页内容，不读取 Cookie、凭据、浏览器存储或隐藏 API。
- 不申请 all_urls；只授予三个槽位中启用的已核实官方域名权限。旧未知站点配置可编辑，但不给读取权限。
- 不登录、不完成验证、不修改或删除远程会话，不把会话送往外部模型。
- 正文不完整或触发人机验证时保留失败原因，不能冒充完整会话。
- 当前界面录入也只允许已启用的官网；读取前后核对实际地址，跨站跳转或切换会话时停止。内容仍标记部分记录，不能放行完整同步。

3.9.0：单次“测试读取”和“录入当前界面”保留。
长对话可点“开始录制”，关闭浮窗并自行上下滚动；重新打开后“停止录制”。
录制仅累计已渲染的消息并去重，120秒自动停止保存。页面切换结束本次录制。
未加载内容无法录入，因此仍标为部分内容。无需新增网站权限或浏览器存储权限。

3.10.0：按消息标识、页面序号和窗口相对顺序合并滚动录制；录制与单页录入使用同一会话身份。仍只支持已识别 AI 官网，120 秒自动停止，未证明完整时保留“部分内容”。检测到冲突顺序会停止并报错，不提交乱序结果。

3.10.0 面板精简：主操作为“开始录制 / 停止并录入”与“测试读取”；网站同步折叠保留。单页录入由开始后立即停止完成，原单页协议仍兼容。
