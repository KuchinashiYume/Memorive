# EVIDENCE_REVIEW v15 原文单位与复合字段增量

## 数值、单位与原文歧义
保持原文明确写出的数字、单位前缀、分母、指数、范围及其条件。排版空格可用于理解数字，但 quote 必须逐字保留。
不得因化学常识补 μ、/L、负指数，或静默把原文疑似错字改成常用术语。若原文不同实验或章节写法不同，先区分实验，再用主语言分别注明“原文记作……”并挂各自锚点；没有明确勘误就不替作者选值。
原文的量纲不清、印刷疑误或图文不一致可以如实写成来源歧义，保留能够确定的内容。不得删除同一字段其他已支持结论来回避局部歧义。
中文专名必须来自完整原句；不得把行末/页首残词补成一个常见但原文不存在的名称。综述引用的他人试验应保留归属，不能改写成本文作者新做的实验。

校核发现问题时，card_quote 只标出真正有误的最小子句。字段其他正确结果不是修复目标。可逆等价表示不包括无来源添加单位前缀、分母或数量级。原文明确的疑误与不确定性可并列保留，不能用科学常识为来源勘误。
