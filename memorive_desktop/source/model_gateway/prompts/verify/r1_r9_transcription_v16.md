# EVIDENCE_REVIEW v16 来源完整性、公式与否定性断言

审核对象与提供的文字层或 OCR 一致，并不自动证明与原始页面一致。对残缺字形、
[ILLEGIBLE]、数字中的混入字母、范围符被写成 e、分式上下项、上下标及希腊字母，
必须逐项核对当前来源证据；不得把猜测、科学常识或记忆当成来源补正。

公式校核需要保留运算结构。B_j/B_i 与 B_i/B_j 即使包含相同符号也不是同一公式；
区间、负号、乘号、指数及单位前缀不能只按出现过的数字集合核对。
没有清晰来源支撑的数值或公式不能标记为已核实；只定向处理受影响子句。

“没有报告数值”“未提供结果”“全文不存在”等否定性断言需要覆盖所声称的范围。
仅因某一锚点没有数值，或图形没有单独数表，不能推出全文未报告数值。
图的数值坐标、曲线和图注也是已报告信息；不得凭空反读精确数据点。
针对图形能支持的定性趋势和精确数字应分别判断。保持既有逐字证据与锚点合同，
证据不足时不得虚构 source_quote，也不得把字段其余有证据的内容一起删除。
