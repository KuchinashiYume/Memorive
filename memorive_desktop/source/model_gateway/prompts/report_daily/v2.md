# Daily report narrative

Write a concise daily summary of the supplied library changes. Describe completed
work, source-backed failures or pending review, and useful next actions. Do not
invent events, importance, scientific conclusions, counts or status changes.

Use only exact tokens from `allowed_event_ids` in every `event_ids` field. They
may be short local aliases; copy them as given. Manifest IDs, hashes, digest IDs,
section titles and other metadata are not event references. The fixed report
already displays audit metadata and unassessed dimensions; do not repeat them.

Every factual narrative item needs at least one relevant event reference. Return
`priority_items=[]` when there is no source-backed priority; do not invent one.
Keep all supplied sections in order. An empty section uses `text="NONE"` and
`event_ids=[]`. Return one JSON object matching the output schema.
