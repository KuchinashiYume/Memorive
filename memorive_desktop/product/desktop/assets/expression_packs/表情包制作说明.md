# 表情包制作说明

表情包决定 Memorive 主窗口（首页、空页、加载中）和桌面助手显示的表情。Memorive 自带"颜文字"表情包，你也可以自己做一个，在 设置 › 外观与辅助功能 › 表情包 里安装。

## 一个表情包是什么

一个文件夹，里面放 `pack.json` 和它用到的图片：

```
我的表情包/
  pack.json
  idle.png
  working.gif
  blink/01.png
  blink/02.png
```

安装时 Memorive 只复制 `pack.json` 和其中写到的图片，文件夹里的其他文件不会复制。

## pack.json

```json
{
  "format": "MemoriveExpressionPack-v1",
  "id": "my-pack",
  "name": "我的表情",
  "author": "某某",
  "version": "1.0",
  "text_style": { "font": "'Yu Gothic UI','Meiryo',sans-serif", "color": "#60B2C0" },
  "looks": {
    "idle": "(>ω-)",
    "working": { "image": "working.gif" },
    "interaction": [ { "image": "wave.png" }, "(・ω<)☆" ],
    "closed": { "frames": ["blink/01.png", "blink/02.png"], "ms": 120, "loop": false }
  }
}
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `format` | 是 | 固定写 `MemoriveExpressionPack-v1` |
| `id` | 是 | 小写字母、数字和 `.` `_` `-`，最长 64 个字符。再装同一 `id` 的包会替换旧版本 |
| `name` | 是 | 列表里显示的名字，最长 64 个字 |
| `author`、`version` | 否 | 作者、版本，各最长 64 个字 |
| `text_style` | 否 | 文字表情的字体 `font`（写法同网页字体，可写几个备选）和颜色 `color`（`#RRGGBB`） |
| `looks` | 是 | 每个表情位显示什么，`idle` 必须写 |

其他字段会被忽略，以后的版本加新字段时，旧的表情包照样能用。

## 表情位

| 表情位 | 在哪里出现 | 没写时用 |
|---|---|---|
| `idle` 常驻 | 桌面助手平时 | 必须写 |
| `open` 睁眼 | 桌面助手眨眼；页面加载动画 | `idle` |
| `closed` 闭眼 | 桌面助手眨眼；页面加载动画 | `open` |
| `greeting` 打招呼 | 打开 Memorive 时的首页 | `interaction` |
| `interaction` 互动 | 点桌面助手；各页首页；工作日志空页 | `idle` |
| `question` 疑问 | 研究问答首页；点首页表情 | `interaction` |
| `working` 处理中 | 桌面助手 | `idle` |
| `success` 完成 | 桌面助手任务完成 | `idle` |
| `saved` 保存成功 | 桌面助手保存成功；当前任务、消息空页 | `success` |
| `error` 出错 | 桌面助手出错 | `idle` |
| `empty` 空页 | 收件箱、资料库空页 | `idle` |
| `message` 新消息 | 桌面助手收到消息 | `interaction` |
| `drag` 拖动 | 拖着桌面助手时 | `interaction` |
| `sleep` 休眠 | 桌面助手休眠 | `closed` |
| `loading` 加载中 | 页面等数据时 | `open`、`closed` 交替 |

## 每个表情位的写法

- 一段文字：`"idle": "(>ω-)"`，最长 40 个字。
- 一张图：`{ "image": "idle.png" }`。可以用 PNG、GIF、WebP、SVG、JPG、BMP，GIF 和 WebP 动图会动。
- 一组帧：`{ "frames": ["a.png", "b.png"], "ms": 120, "loop": true }`。`ms` 是每帧显示的毫秒数（20 到 10000），可以写一个数，也可以每帧写一个；`loop` 写是否循环，不写就循环。最多 240 帧。
- 一个列表：`[ ... ]`，里面放上面三种，每次出现时随机挑一个，最多 32 个。

## 桌面助手

- 文字表情画在白色圆角卡片上，颜色用 `text_style` 的颜色。
- 图片不画卡片，按透明背景显示，缩放进一个方框。
- 桌面助手能显示 PNG、GIF（含动图）、JPG、BMP 和帧动画。WebP、SVG 只在主窗口里显示；桌面助手遇到时用同一表情位里能显示的那个，没有就用常驻表情，常驻也没有就显示 Memorive 标志。给桌面助手用的表情请用 PNG、GIF 或帧动画。

## 动画

两个文字表情之间切换时放"解码"换脸动画；连点首页表情五次的乱码彩蛋也只对文字表情。涉及图片的切换直接换图。

## 限制

- 图片放在表情包文件夹里，可以放子文件夹，路径用 `/` 分隔，不能用 `..` 指到包外。
- 单张图不超过 16 MB。
- 安装时检查不通过，设置里会写出是哪一条。

## 安装、更新和卸载

- 设置 › 外观与辅助功能 › 表情包 › 从文件夹安装表情包，选中你的表情包文件夹。装好后马上使用。
- 改了表情包后再安装一次，同一 `id` 会替换旧版本。
- 也可以点"打开表情包文件夹"，把表情包文件夹直接复制进去，再回到列表里点"使用"。
- 卸载自己装的表情包会把它移到回收站。颜文字包卸载后仍在列表里，可以再装。
- 包里的图片由制作者负责版权；分享别人画的图之前，先确认作者同意。
