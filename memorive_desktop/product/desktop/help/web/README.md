# Memorive 三语言离线文档

直接双击 `index.html` 打开。右上角可切换简体中文、English、日本語；左侧可切换使用指南与总体设计。搜索、页内目录、图片原图、PDF 和 Markdown 文件都可在本地使用。指南第一章展示“读、理、证、存”四个特色入口。

复制或移动网页时，请保留整个 `web` 文件夹；单独复制 `index.html` 会丢失正文、图片和下载文件。

使用指南的完整图文版位于 `../<语言>/manual.md` 和 `manual.pdf`，纯文字版位于 `manual-text.md`。网页版“替换本语言正文”只修改当前浏览器的本地存储，点击“恢复默认”可回到交付正文。

架构、交互和验证边界见 [WEB_DESIGN.md](WEB_DESIGN.md)。
