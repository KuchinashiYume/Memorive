# Memorive 本地文档网页设计与实现说明

版本：2026-09-29 · v1.02 发布前修订。适用语言：简体中文、英语、日语。

## 1. 定位和依据

这个网页是可直接从本地文件夹打开的文档阅读器。正文来自本交付中的三语言《使用指南》和三语言《总体设计》，让读者在同一个界面中按任务学习、查阅设计依据、查看配图、获取原始文件。它不连接模型服务，不替代桌面程序的设置或研究操作。

设计依据：

- 使用指南的 18 个任务章节构成“使用指南”导航，包括模型服务、CLI、本地模型、流程模型映射、文献处理、研究问答、引用查证、检索权重、会话、网页读取、排行榜、计费等。
- 总体设计原有的章节、附录和新增模块章节构成“总体设计”导航。网页保留原文措辞与引用，并按实际顺序生成唯一的网页地址，避免正文编号、罗马数字、附录编号造成链接冲突。
- 配图沿用指南和设计文档的本地资源。指南中的测试或空状态截图必须以文字标明其证据边界；流程示意图只解释操作关系，不当作真实研究证据。

## 2. 信息架构

桌面宽度采用左、中、右三栏：左栏切换文档、搜索并选择章节；中栏阅读正文、图片和前后篇；右栏显示本页小目录及文件操作。窄屏隐藏右栏；手机宽度用顶栏按钮展开左侧目录，主内容占满可用宽度。顶栏始终提供语言切换。

每种语言都有两套完整内容：16 篇使用指南、16 篇总体设计。网页路径采用 `#语言/文档/章节`，例如 `#zh-CN/manual/09`、`#en-US/design/13`。可复制链接后在同一文件夹内重开。章节路径按原文出现顺序编号为 01–16；正文标题仍展示原文编号和标题。使用指南第一章保留“读、理、证、存”四个入口特征，与 PDF 首页对应。

语言切换保持当前文档类别和章节位置。两个文档之间切换也尽量保持位置；如果导入的用户 Markdown 没有对应章节，则回到该文档第一章。浏览器地址栏中的路径优先于上次保存的语言偏好。

## 3. 页面和交互

### 3.1 阅读

左侧显示完整章节列表和当前选中状态；右侧显示当前章的三级、四级标题。点击小目录滚动到相应段落。正文支持段落、列表、表格、行内代码、图片和外部 HTTPS 参考链接。图片在正文中保持适中尺寸，点击可在新标签中打开原图。底部的“上一篇/下一篇”按正文顺序移动，首尾不可继续的按钮禁用。

### 3.2 检索

搜索框在当前语言、当前文档内按章节标题与正文文字筛选左栏条目，不改变正文，也不触发网络调用。`Ctrl+K` / `⌘K` 将焦点移到搜索框。空结果显示本地化提示。清空搜索后恢复全部章节。

### 3.3 阅读辅助

三个字号档位与较小档位通过 `A−`、`A+` 控制；当前字号保存在本地浏览器。打印按钮交给浏览器打印当前网页，打印样式去掉导航和工具。复制按钮复制当前章节的完整本地地址。所有关键按钮与输入框保留键盘焦点样式；随语言更新可见标签和辅助技术标签。

### 3.4 文件

每种语言、每类文档都有 PDF 和 Markdown 下载目标。指南另提供不带配图语法的纯文字 `manual-text.md`；同文件夹里的 `manual.md` 保留图片引用及 `assets` 文件夹。网站的 PDF/Markdown 链接均指向打包内的本地文件。离线状态只表示资源已在本地，不代表桌面程序或模型连接正常。

### 3.5 替换指南正文

“替换本语言正文”接受小于 2 MB、至少含一个 `##` 章节标题的 Markdown 文件。它把所选语言的使用指南正文保存在当前浏览器的 `localStorage`，不写回交付文件，也不改变其他语言或总体设计。导入器只解析安全的文字结构，不执行输入文件中的 HTML、脚本或远程资源；图片语法在替换稿中作为文字说明，原配图仍由交付资源提供。“恢复默认”移除当前语言的本地替换并立即显示交付版本。下载 Markdown 时，若当前语言已有替换，则下载该替换稿。

## 4. 本地数据与文件结构

`index.html` 是入口，`app.css` 定义布局与暖色视觉系统，`app.js` 管理路由和交互，`content.js` 固化三语言正文。`assets/<语言>` 存放使用指南配图；`design-assets/<语言>` 存放总体设计配图；`downloads/<语言>` 存放两种文档的 PDF/Markdown 与指南纯文字稿。整个网页不依赖服务器、CDN、外部字体或接口。

正文与设计资源在构建时生成快照。更新文档后，应重新生成 `content.js` 和对应下载文件，并用相同语言逐一核对标题、图片和 PDF。浏览器中的用户替换属于个人本地状态，不能视为正式文档版本。

## 5. 视觉规则

采用接近 v14 设计文档的暖白纸面、浅米色侧栏、陶土色强调和浅棕分隔线。中文正文用 Times New Roman 显示英文及数字、宋体显示汉字；中文标题和着重字用 Arial 显示英文及数字、黑体显示汉字。英文正文采用 Times New Roman，标题与着重字采用 Arial。日文正文采用游明朝，标题与着重字采用游ゴシック；缺少字体时由系统衬线或无衬线字体接续。网页不下载外部字体。图文稿保留原始截图与可点击原图；PDF 将截图的有效操作区域放大呈现，便于看清控件和字段。键盘焦点采用可见轮廓，正文文字与背景保持清晰对比。

## 6. 边界和后续集成

桌面程序通过“设置 → 关于与版本 → 使用文档”调用既有帮助入口，并按语言打开本地网页或 PDF。本次更新沿用该入口，不改为新的在线服务。文档与最终程序的包身份仍须在交付时核对；本地阅读器检查不能替代实际程序的帮助入口与安装后资源检查。应用中的配置字段、按钮名称与流程状态发生变化时，先更新指南和截图，再重新构建网页与 PDF。
