# Memorive 配套插件

[English](README.en.md) · [日本語](README.ja.md)

插件把 Obsidian 笔记、Zotero 文献与批注接入 Memorive，可预览导入、检索证据、提交问答，并把结果写回笔记。仅在 Windows 桌面使用，通过本机 Memorive.exe 通信，不在插件中保存模型 API 密钥。问答使用本体保存的模型设置，可能产生模型费用。

## 安装与连接

1. 安装并打开 Memorive，在「设置 → 研究问答与连接 → Agent 与连接」查看接入配置。在「连接与同步」创建对应的 Obsidian 或 Zotero 连接，选择所属项目和允许读取的资料目录。
2. **Obsidian**：把 `obsidian/memorive-companion` 文件夹复制到目标笔记库的 `.obsidian/plugins/`，重新加载插件列表并启用 Memorive Companion。单独下载 ZIP 时先解压，确保 `manifest.json` 位于该插件目录内。声明的最低版本为 Obsidian 1.5.0；历史宿主验证使用 1.13.7，不代表所有版本均已验证。
3. **Zotero**：在插件管理器选择「从文件安装插件」，选择 `zotero/memorive-companion.xpi`。当前兼容声明限定 Zotero 10.0.x、个人库；群组库尚不支持直接连接。
4. 在插件的 Memorive 设置中填写 **Memorive.exe 绝对路径、研究工作区路径、项目 ID、连接 ID**。工作区必须是本体已初始化的研究工作区，不是程序安装目录，也不是 Obsidian 笔记库。使用本体提供的路径，不要猜测。
5. Obsidian 可先「验证连接」再获取已授权连接；Zotero 在「Memorive 连接」中获取连接并保存。路径或项目改变后需要重新配置。

## 日常使用

- Obsidian：打开笔记，用命令「将当前笔记送往 Memo（预览）」或文件菜单选择资料；查看新增、更新及未变化的项目，再确认导入。通过研究侧栏或选中文本检索查看来源。
- Zotero：选择文献条目或其 PDF，点击「送往 Memo（预览）」。本地 PDF 需已下载；批注随所选附件一同读取。核对预览后确认导入。
- 在侧栏检索证据，查看页码、行号或来源链接；简短提问与 Agent 请求进入本体队列，需保持 Memorive 打开。插件不会替你审批知识草稿。
- 回写前在本体连接设置中允许回写，再选择结果。Obsidian 使用受管理的笔记区块，Zotero 使用专属子笔记；检测到修改冲突时保留现有内容并提示另存。建议首次在新建的空白库验证。

## 更新、隐私与限制

插件版本为 1.0.0，面向 Memorive 1.01。源码及安装包随主项目维护，暂不承诺自动更新；私有仓库期间需具备仓库访问权限。更新文件保留空列表，不宣称已有可用的自动更新服务。

插件设置保存在各宿主的本地配置中，包含所选路径和连接信息；这些设置、个人笔记、文献库及测试数据不随插件分发。模型服务的数据处理遵循本体配置和相应服务条款。插件本身不嵌入 WebView2，Microsoft 组件说明见本体许可与隐私文档。

出现「工作区未初始化」时重新复制本体工作区路径；出现「连接不存在／禁用」时核对项目、连接及授权；问答排队时确认本体已打开。插件验证与历史宿主测试不能替代你所用宿主版本的实际验证。

源码许可证和 AI 开发说明见 [NOTICE.md](NOTICE.md)。另附 developer SDK 与 Agent skills，供需要自行接入的用户使用。

## 从源码打包

在仓库根目录运行 `python memorive_desktop/tools/package_companions.py --output <新的输出目录>`。工具仅使用声明的插件源码，生成 Obsidian ZIP、Zotero XPI 和校验清单，不读取宿主配置或用户资料。
