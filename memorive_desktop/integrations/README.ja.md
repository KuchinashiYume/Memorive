# Memorive 連携プラグイン

[中文](README.md) · [English](README.en.md)

Obsidian のノートや Zotero の文献・注釈を Memorive に取り込み、根拠の検索、質問、研究結果の書き戻しを行えます。Windows デスクトップ専用です。ローカルの Memorive.exe を呼び出し、プラグインにモデルの API キーを保存しません。質問には本体のモデル設定が使われ、利用料金が発生する場合があります。

1. Memorive の接続設定で Obsidian または Zotero 接続を作成します。実行ファイルの絶対パス、初期化済み研究ワークスペースのパス、プロジェクト ID、接続 ID を本体からコピーしてください。
2. Obsidian：`memorive-companion` フォルダーを保管庫の `.obsidian/plugins/` に配置し、プラグイン一覧を再読み込みして有効にします。宣言上の最低バージョンは 1.5.0、過去の実機確認は 1.13.7 です。全バージョンの動作確認を意味しません。
3. Zotero：プラグイン管理画面から `zotero/memorive-companion.xpi` をインストールします。対象は Zotero 10.0.x の個人ライブラリーです。PDF 添付は事前にダウンロードしてください。
4. プラグイン設定にコピーしたパスと ID を入力し、接続を確認します。研究ワークスペースはアプリのインストール先や Obsidian 保管庫とは異なります。Zotero では接続を取得して選択を保存します。
5. ノートや文献を選択して取り込み内容をプレビューし、確認後に実行します。研究サイドバーでは引用とページ・行番号を確認できます。質問と Agent への依頼は本体のキューに入るため、Memorive を起動しておいてください。
6. 書き戻しには本体側の許可が必要です。管理対象のノート区画、または Zotero の専用子ノートに保存します。変更の競合時は既存内容を保持し、別名保存を選べます。最初は空の保管庫で確認してください。

プラグイン 1.0.0 は Memorive 1.01 向けです。更新は手動で行い、自動更新サービスの提供は約束していません。非公開リポジトリの取得にはアクセス権が必要です。個人設定・文献・テストデータは配布物に含めません。モデルへのデータ送信は本体設定とサービス規約に従います。プラグイン自体は WebView2 を内蔵しません。

[ライセンスと AI 開発に関する表示](NOTICE.md)をご覧ください。開発用 SDK と Agent skills も含みます。`python memorive_desktop/tools/package_companions.py --output <新規フォルダー>` で配布物を生成できます。利用するホストのバージョンでの動作確認は別途必要です。
