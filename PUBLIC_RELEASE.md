# Public release status

The maintainer has authorized public release of Memorive v1.01. The default GitHub homepage and release description are in English; Chinese and Japanese guides remain available. This documentation change does not alter application, installer, console, or saved user language preferences.

The GitHub Release identifies the published source commit and downloadable files. `SHA256SUMS.txt` binds each attached distribution file. The original application and console executables remain the tested, unsigned files; no application code or executable was changed for the English homepage update.

Some embedded build manifests and review notices were generated while the repository was private and retain their candidate status. They record packaging-time provenance. The maintainer's later publication decision is recorded here and in the GitHub Release; it does not expand the verified test scope or confer rights to third-party artwork.

Original code is licensed under AGPL-3.0-only. Character artwork and third-party components retain their separate notices. See [licensing scope](LICENSING.md), [application artwork](memorive_desktop/ASSET_NOTICE.md), [console artwork and privacy](memorive_console/NOTICE.txt), and the component notices. No official affiliation or independent artwork redistribution authorization is claimed.

Verification scope: [application](memorive_desktop/RELEASE_CHECKS.md) and [console](memorive_console/VERIFICATION.md). English remains the default only for this GitHub presentation; this release does not claim a new full application, VM, real-document, or model test run.
