# Memorive Test Console 1.03

- **Three languages.** Switch between English, Chinese and Japanese with the globe button, as in the Memorive installer. The console remembers your choice and keeps your open session and form entries when you switch.
- **Review and results view.** Automated checks and nine groups of manual feature and UI checks are shown separately.
- **Shareable summaries.** Export a review summary as Markdown or JSON, tied to the tested executable and session. Exports leave out document content, settings, file paths and tokens.
- **Clearer reports.** Suite reports show whether each result came from the reference self-check or from your own Memorive build. The suite formerly labelled as a full-product regression is now called "Safe bridge regression".
- Version information updated to 1.03. Existing operation IDs and protocol 1.0 still work. Raw receipts, operation IDs and error codes stay in their original form so you can match them with logs.

## 中文

- **三语界面**：像 Memorive 安装程序一样，用地球图标在中文、英文和日文之间切换。控制台会记住你的选择，切换时保留当前会话和已填写的内容。
- **审核与结果页面**：自动检查和九组人工功能、界面检查分开显示。
- **可分享的审核摘要**：可以把审核摘要导出为 Markdown 或 JSON，摘要会关联被测程序和会话；导出内容不包括资料正文、配置、文件路径和令牌。
- **更清楚的报告**：测试报告会标明每项结果来自参考自检，还是来自你自己构建的 Memorive。原先标为“全量回归”的测试改名为“安全接口回归”。
- 版本信息更新为 1.03，原有的操作 ID 和 1.0 协议继续可用。原始回执、操作 ID 和错误码保留原文，方便和日志对照。

## 日本語

- **三言語表示**：Memorive のインストーラーと同じく、地球アイコンで日本語・英語・中国語を切り替えられます。選んだ言語は記憶され、切り替えても開いているセッションや入力中の内容はそのまま残ります。
- **レビュー・結果画面**：自動チェックと、9 グループの手動の機能・画面チェックを分けて表示します。
- **共有用のレビュー概要**：レビュー概要を Markdown または JSON で書き出せます。概要はテストした実行ファイルとセッションに結び付けられ、資料の本文、設定、ファイルパス、トークンは含まれません。
- **わかりやすいレポート**：各結果が参照セルフチェックによるものか、自分でビルドした Memorive によるものかを表示します。以前「全体回帰」と表示していたテストは「安全なインターフェース回帰テスト」に名前を変えました。
- バージョン情報を 1.03 に更新しました。既存の操作 ID とプロトコル 1.0 は引き続き使えます。元の応答、操作 ID、エラーコードは、ログと照合しやすいよう原文のまま表示します。
