# Memorive Test Console 1.03

- Chinese, English and Japanese UI with Memorive installer-style globe control; remembers selection and preserves edited forms and the active session across language changes.
- Review and results workspace separates automated bridge receipts from nine groups of manual feature/UI checks.
- Markdown and JSON review summaries bind the executable hash and session; export excludes business bodies, configuration, file paths and tokens. Cleanup status is updated at normal session close.
- Explicit reference-peer versus application evidence in suite reports. Test passes never imply automatic product release acceptance.
- Safe bridge regression replaces the misleading full-product regression label. Existing operation identifiers and protocol 1.0 remain compatible.
- Installer and executable version metadata updated to 1.03. Logo, per-user installation identity, temporary-session cleanup and model-call restrictions retained.

本版增加三语界面、安装工具风格的语言入口、独立人工检查和可分享的审核摘要。原始回执、操作 ID 与错误码不翻译；模拟测试不代表本体全部功能通过。

本版は三言語表示、インストーラーと同様の言語切替、独立した手動確認、共有用レビュー概要を追加します。元の応答・操作 ID・エラーコードは翻訳しません。模擬テストは製品全体の検収ではありません。
