# Licensing scope

See [Memorive licensing scope](memorive_desktop/LICENSING.md). Character artwork is excluded from the code license.

The original software code in `memorive_console/` also uses AGPL-3.0-only. Its [separate notice](memorive_console/NOTICE.txt) identifies the console icon's original artist and explains its rights limitations. This icon is not covered by the desktop application's AI-generated-artwork description. The console's dependencies have their own [license inventory](memorive_console/THIRD_PARTY_NOTICES.md).

Memorive Test Console supports modifying and testing the application in temporary sessions. Test results describe only the selected executable, configuration, and scenarios; they do not certify general quality or security.
