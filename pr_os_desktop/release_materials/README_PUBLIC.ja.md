# Memorive

[プロジェクト](https://github.com/KuchinashiYume/Memorive) · [リリース](https://github.com/KuchinashiYume/Memorive/releases) · [問題の報告](https://github.com/KuchinashiYume/Memorive/issues)

[中文](README_PUBLIC.md) · [English](README_PUBLIC.en.md)

Memorive は、個人の学習・研究向けのデスクトップ文献ワークスペースです。資料の整理、研究に関する質問、引用元の確認を一つのアプリで行えます。

## AI による開発について

Memorive は AI コーディングツールで開発されたプロジェクトです。本プロジェクト独自のコードは **OpenAI Codex と Anthropic Claude Code** によって生成・修正され、改善が重ねられています。企画者は要件定義、製品設計、テストと受け入れ確認を担当しており、**コードを直接書いてはいません**。第三者のコンポーネントについては、それぞれの作者をクレジットしています。詳しくは第三者に関する説明をご覧ください。

## 主な機能

- 文献や Web ページを取り込み、処理状況を確認しながらライブラリを整理。
- 手元の資料について質問し、回答の引用と参照箇所を確認。
- 会話を整理し、研究の記録を次の作業に引き継ぐ。
- マニュアルに従って API サービス、対応する CLI、ローカルモデルを設定。
- モデルのランキング、使用量、費用の記録を確認。外部の価格や順位は変わることがあります。

モデルの回答と引用は利用者自身で確認してください。費用の記録はサービスや実行経路から取得できる情報に依存し、サービス提供元の請求書に代わるものではありません。

## 利用を始める

動作対象：Windows 10 22H2 以降、または Windows 11（x64）。.NET Framework 4.8、Microsoft WebView2 Runtime、Visual C++ v14 x64（14.51.36247 以降）が必要です。Python はアプリに同梱されます。

インストーラーは必要なコンポーネントを確認し、不足している場合は Microsoft の公式ダウンロードページを案内します。コンポーネントのインストール後に、もう一度確認して続行してください。初回の準備にはインターネット接続が必要な場合があります。コンポーネントがそろっていれば、アプリはオフラインでインストールできます。WebView2 の更新、SmartScreen、データの取り扱いについては[第三者に関する説明](THIRD_PARTY_NOTICES.md)をご覧ください。

1. このリポジトリの Releases ページからインストーラーと SHA256 チェックサムを取得します。
2. プログラムとデータの保存先を別々に指定します。公開版は初期設定の状態で開始し、作者の文献、会話、モデルの認証情報は含みません。
3. 設定画面でモデルサービスを接続します。クラウドサービス、CLI の契約、ローカルモデルは各自で用意してください。本ソフトウェアは無料の API 利用枠を提供しません。
4. 資料を一つ取り込み、研究について質問して引用元を確認してから、ライブラリを広げてください。

中国語・英語・日本語の利用マニュアル、設計文書、ローカルのドキュメントページをアプリに同梱します。ソースからのビルド方法は [BUILDING.md](BUILDING.md) を参照してください。
