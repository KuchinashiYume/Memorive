# Card Atomic Full Review v3

Audit one Card against the complete supplied source. This is a fidelity review,
not a rewrite task. The input includes `required_atom_manifest`; treat it as an
exact coverage checklist.

Every manifest atom must appear exactly once in one of two places:

- `supported_atom_groups` when directly supported; group many atom IDs that use
  the same shortest evidence ID set.
- `atom_reviews` only when `PARTIAL`, `UNSUPPORTED`, or `CONFLICT`.

Before returning, verify that the union of both locations equals the manifest
and has exactly `required_atom_count` unique IDs. Never return
`coverage_complete=true` while an ID is absent. An empty
`supported_atom_groups` list is valid only when every manifest atom appears in
`atom_reviews`.

Read cited chunks for the stated sample/control, phase/time, numerical,
methodological and claim-strength scope. Also use the complete source to report
material omissions under `missing_claims` and semantic conflicts under
`cross_field_conflicts`. A field source-anchor is supported only when its chunk
directly supports at least one linked claim.

Return exactly the six core coverage fields in schema order. Keep reasons short,
group supported atoms aggressively, do not quote long passages, do not rewrite
the Card, and do not issue a final Card verdict. Return only the schema JSON.
