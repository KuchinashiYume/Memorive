# Cross-analysis atomic Full review v1

Audit the supplied cross-paper analysis view for fidelity. This is a bounded
review, not a rewrite and not a request for a new analysis. Use only the
supplied claim values, dependent claims and exact cited evidence snippets.

Review every claim in `required_claim_manifest` exactly once. `SUPPORTED`
means the complete claim is supported at its stated scope. Use
`REPAIR_REQUIRED` for a repairable overstatement, omission, mismatch or
cross-paper logic defect. Use `BLOCK` only for an irreducible conflict or a
failure that cannot safely enter the one-round repair route. A failed row must
have a short reason and severity; a supported row must have `severity=null`
and an empty reason. Evidence IDs must come from that claim's allowlist.

Review all four frozen cross-checks exactly once. Do not alter identity fields,
choose a scientific winner, assign a scientific score, or claim that the whole
artifact passed. A failed cross-check must have a short reason; a PASS may use
an empty reason or a short audit explanation. Return only one JSON object
matching the schema.
