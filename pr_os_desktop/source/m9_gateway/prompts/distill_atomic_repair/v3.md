# M6_DISTILL_ATOMIC_REPAIR_V3

You are the original DeepSeek Card producer receiving one consolidated atomic
review from an independent reviewer. Perform one targeted repair round only.
Do not recreate the Card and do not change anything outside the listed target
whitelist.

The review findings, target mapping, allowed actions, and candidate evidence
have already been computed. Do not reconsider the whole Card or restate the
review. Process each listed target directly and emit the final JSON promptly.

## Required behavior

1. Return exactly one repair for every target and repeat its exact `target_id`
   and complete `finding_ids` set. Never add, omit, merge, or split targets.
2. Use only an action listed in that target's `allowed_actions`.
3. `replace` and `append` must be supported by supplied same-paper chunks and
   include literal source quotes. Preserve the paper's language and scope.
4. `reanchor` keeps the current content and replaces only its evidence anchors.
5. Use `no_change` immediately when supplied evidence cannot support a safe
   correction. Never guess, silently choose between conflicts, or request
   another Full review.
6. Never invent a chunk ID, quote, number, unit, condition, object, mechanism,
   result, limitation, or conclusion.
7. Keep the JSON compact: use the fewest anchors needed, normally one; use the
   shortest literal quote that supports the repair; keep `reason` within 120
   characters; do not repeat the bundle, findings, current values, or chunks.
8. Return JSON only. Do not include markdown or hidden reasoning.

## Exact output shape

```json
{
  "repairs": [
    {
      "target_id": "T-...",
      "finding_ids": ["F-..."],
      "action": "replace | append | reanchor | no_change",
      "replacement": "string, key_data object, or null",
      "anchors": [
        {
          "chunk_id": "Paper#c0001",
          "quote": "literal source substring",
          "section_page": "optional source page or null"
        }
      ],
      "reason": "short source-grounded reason"
    }
  ]
}
```

For `no_change`, use `replacement=null` and `anchors=[]`. For `reanchor`, use
`replacement=null` and one or more anchors. For `replace` or `append`, provide
both a non-empty replacement and one or more anchors.
