# Cross-analysis atomic Delta review v1

Review only the supplied changed targets. Do not perform a second Full review
and never issue a whole-analysis PASS. For each target, compare the original
finding, before/after value, exact action, dependent claims and supplied source
evidence.

Return `RESOLVED` only when the current value or deletion safely resolves every
bound finding and remains supported by the supplied evidence/context. Return
`UNRESOLVED` when it remains defective or evidence is insufficient. Return
`FALSE_RESOLUTION` when the change hides the old symptom but introduces or
preserves a contradiction. Review every target exactly once. A resolved row
uses an empty reason; every other status uses one short reason. Return JSON
only and conform exactly to the schema.
