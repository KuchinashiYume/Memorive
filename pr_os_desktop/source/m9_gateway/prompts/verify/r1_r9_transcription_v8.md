# M6 搬运类校核 · v8 语义冲突阈值增量

> 本文件追加在不可变 v6 与 v7 之后。v8 只校准“什么才是冲突”，
> 不放宽 JSON、逐字 quote、同论文锚点或 fail-closed 契约。

## direct_conflict 的必要条件

只有卡片命题与原文命题在同一对象、指标、时间/阶段、方向、数值和作用域下**逻辑上不能同时成立**，才可报告 `direct_conflict`。措辞不一样不等于命题冲突；先比较事实，再决定是否报 R1–R9。

下列情况本身不得报违规：

1. `sample` 中的 `A vs B` 只表示比较范围或两个端点。原文写“从 B 到 A 上升/下降”，只要端点、数值和方向与 Card 其余字段一致，就是支持关系，不是方向冲突。
2. Card 与原文的数值、单位、指标、对象、方向、阶段均一致，只是一个写范围标签、另一个写完整句。
3. 同义改写、语序变化、单复数或不改变命题的虚词差异。
4. 明显的 PDF 词内空格、断词、连字或转换噪音；例如 Card 的连续词与原文被异常空格拆开，或原文多出不构成新术语/否定/数值/对象的疑似转换字符。若差异改变科学术语、否定关系、数字、单位、对象或条件，仍须报告。

## 来源自身互相矛盾

若给定 chunks 自身包含不能同时成立的两种说法（例如摘要写 5 台而方法写 8 台），不得因其中一处支持 Card 就静默放行。可使用 `direct_conflict` 引用与 Card 冲突的那一处；本地程序会在卡片摘录也逐字出现于另一处锚定原文时标记为“锚定原文内部冲突”，避免把出版物自身矛盾误写成 Card 单方臆造。

## 输出前语义自检

- 这两个命题能否同时为真？能 → 不报冲突。
- 差异是否只在排版、空格或等义表达？是 → 不报冲突。
- `A vs B` 是否仅为比较端点？是 → 结合 value/stat 判断，不能把 `vs` 自行解释成方向。
- 只有事实不相容且两侧逐字证据齐全，才输出 violation。
