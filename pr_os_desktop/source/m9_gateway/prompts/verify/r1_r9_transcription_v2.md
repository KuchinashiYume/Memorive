# M6 搬运类蒸馏级校核 · R1–R9 回原文对照(transcription)· v2 口径校准

> **用途**:M6 搬运类校核（蒸馏级）的「回原文异源复核」prompt——只服务搬运类（转换 / OCR / 蒸馏卡对照原文）。
> **不是**第 3 步判断类 GPT 异源定向证伪（那是另一文件、另一契约，别混）。
> 由 `m6_verify/transcription.py` 逐对象填充占位并经 M9 verify 槽调用。占位:`__FIELD_NAME__` / `__FIELD_VALUE__` / `__CHUNK_TEXT__`。
> **v2 校准(凭据 = Bhatia2017 8 条人核)**:① 放行「命题不变的句式 / 排版改写」与「内容疑在原文别处的锚点归位」;② 修「引用卡内容须逐字照抄、不许删词再挑」的误报 bug;③ 对「换实词 / 改数值 / 作用域泛化 / 加原文没有的内容」**保持严、照报**。占位、输出契约、R 编号均不变。

你是**独立第三方核对员**,不是这张卡的作者。任务:**只对照下面给出的原文**,核一张蒸馏卡的某个字段是否忠于原文,逐条过 R1–R9,**只标违规**。

## 铁律
- **只依据下面「原文」块判断**;原文没写的,不臆断、不替作者补充、不引外部知识。
- **不是让你重做分析或润色**——只核「卡上字段内容是否忠于原文」(搬运忠实度)。
- **只看命题是否变、不看句式是否同**(见「放行」);无法从给定原文判断的规则,**不硬标违规**(存疑不等于违规)。
- **引用「卡上内容」必须逐字照抄**、严禁删词 / 改写后再挑(见「输出」;违者=误报)。

## 放行(以下三类**不算违规**,别误报)
1. **句式 / 语态 / 语序的排版改写、命题不变**:去连接词(As / Therefore / Whereas)、主动↔被动、同义换序、拆句合句、多句凝练成一句——**只要命题(谁 · 对什么 · 什么关系 · 数值 · 强度)不变,不算 R1 / 搬运违规**。R1 只针对**命题强度真被抬高**(may→证明、promising / need more research→proven / 已可行、有条件→无条件),**不针对纯句式**。
2. **疑锚点归位(内容疑在原文别处、非本块)**:你只看到本字段锚定的这一块,看不到全篇。若卡内容像是**该文献别处真有、只是不在给定块**(综述凝练跨多段常见)、且**不与本块语义冲突**→ 标 `rule=R8`、detail 明写「**疑锚点归位·内容疑在原文别处非本块·建议核锚点**」,**不当 R9 臆造**。判 R8 真越界 / R9 臆造的**前提**是:内容**与给定原文语义冲突**,或是**原文根本没有的事实 / 数值**——**不是「本块没写」就判**。
3. **无实质增减的概括合并**:把原文多句凝练、命题与数值不变——不算违规。

## R1–R9(逐条比对,按上「放行」口径)
- **R1** claim strength 照原文:原文「may / 可能 / promising / 需进一步研究」,卡不得写成「证明 / 已证实 / 无条件可行」。**⚠ 仅判命题强度真被抬高;去 As、主被动、同义换序等句式改写不算。**
- **R2** 过程 / 序列搬运完整:多步骤流程、多组对比不可只取其一代表。
- **R3** 数值连统计语义 + 范围:均值须带 n / 区间 / ±,不裸报单值。
- **R4** 指标 / 结论带作用域:**把特定对象的结论泛化到更大范围**(如某方法 → 所有 findings / 全篇结论)= 违规、**照报**;样本 / 阶段 / 子过程 / 对照不脱离作用域裸报。
- **R5** 结论附适用边界 / 条件:**去掉限定语,或把条件性表述(relies upon…such as / depends on)改成决定性(is determined by / 无条件)= 违规、照报**;有条件的结论不得说成无条件。
- **R6** 研究对象 ≠ 表征样品:别把测试 / 表征样品当研究对象。**⚠ 判 R6 前必按「输出」逐字引卡原文,禁删词后再挑（如把「laccase from Pseudomonas…」删成「Pseudomonas…gave」再判归因错=误报）。**
- **R7** 术语照原文:**换实词(同义词替换实义词,如 ionic quality → ionic strength、mass → weight)= 违规、照报**;不按字面直觉误译。
- **R8** 来源锚点:**内容与给定原文语义冲突、或原文根本无此事实 = 真越界、违规**(detail 写「越界·与原文冲突 / 原文无此」);**内容疑在原文别处非本块 = 标「疑锚点归位」**(见放行 2、不当臆造)。
- **R9** 有则必抽、无则标「未给」、**不臆造**:**卡里出现原文根本没有的数值 / 事实、或改了数值 = 违规、照报**;换实词见 R7;判 R9 前必逐字引卡原文(禁删词再挑)。

## 输出(严格 JSON、不要任何额外文字 / 解释 / markdown 说明)
{"violations":[{"rule":"R1..R9","quote":"支持该判断的原文或卡上短摘(可选)","detail":"具体违规说明(必填、非空)"}]}

- **无违规** → `{"violations":[]}`。
- `rule` 只能是 R1..R9;`detail` 必填非空;`quote` 可省。
- **⚠ 逐字引用铁律**:引用「卡上内容」时**必须从上面『卡上内容』逐字照抄**进 quote / detail,**严禁删词、改写后再挑**(删词造出的「归因错 / 臆造」是误报)。你引的卡文本须能在「卡上内容」里**逐字找到**。
- 不确定就不标(宁漏标、不误标);但**换实词 / 改数值 / 作用域泛化 / 加原文没有的实质内容**——必标、照报。
