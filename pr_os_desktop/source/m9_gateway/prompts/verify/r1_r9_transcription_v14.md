# M6 搬运类校核 · v14 语境来源与等价表示增量

> 本文件只追加在 v10 基线与 v13 增量后。它不改变三种 evidence relation、
> 四字段 JSON 或逐字证据门；只收紧语义对象、等价表示和字符来源判断。

## 可逆等价表示不得报 R7

- 实义术语是否“不同概念”必须按科学命题和下游操作判断，不按词面判断。两个量若只是**可逆、互补或单调等价表示**，且样本间关系、排序、距离、检验对象、方向与方法结论不变，不得报 R7 或 direct_conflict。
- 例如同一量用 `x` 与 `1-x`、正向分数与其互补距离、比例与百分数表达，只要转换关系明确且没有改变科学命题，就是等义表示。不得因为名称不同就假设方法不同。
- 只有两种表示无法通过明确可逆关系对齐，或转换后会改变对象、方向、阈值、排序、统计检验或结论时，才可能属于 R7；仍须给出不能同时成立的双侧逐字证据。

## direct conflict 必须完全同作用域

- 报 direct_conflict 前，必须逐项对齐对象身份、群体层级、阶段、处理组、测量指标与统计口径。**不同对象、群体层级、阶段或统计口径**的两句话不得拼成冲突。
- 整体群落、某个子群、单个分类单元、功能表现和组成/多样性是不同层级；一个层级恢复而另一层级仍不同可以同时成立。只有 Card 与 source 明确谈同一层级和同一指标时才可比较。
- 来源内部同时出现支持句与相反句时，也必须先做上述作用域对齐；“来自同一篇论文”本身不等于同一命题。不能排除层级或指标差异时不报。

## R8 仍是锚点债，不是词面搜索

- `missing_from_given_chunks` 判断的是科学子主张在该字段全部锚定 chunks 中是否得到支持，不要求 Card 句子逐字出现。缩写/全称、结构化槽位、跨句凝练或等价表示得到支持时不得报 R8。
- 若结构化 key_data 的数值有支持，但它额外写入的处理组、重复数、比较基线、显著性或条件在该条全部锚点中均无支持，可只对那个最小附加子主张报 R8；不得把已支持的 value/metric 一并判错。
- 叙述字段把多个分别受支持的方法步骤合并为一句时，不得仅因整句不连续出现而报 R8；但其中任一方法、工具、样本或条件在全部字段锚点均无支持时，仍应按最小子主张报 R8。

## 非英文字母的来源判断

- **人名、文内引用、变量、希腊字母**、带变音符号字母以及其他非英文字母都可能合法出现在作者名、正文引用、公式、单位、统计符号、分类学名称或多语言正文中。
- 这些字符的出现本身不是 legacy、乱码、术语替换或任何 R1--R9 违规证据。不得建立字符白名单，不得按字符形态判错。
- 只有在双侧逐字内容与上下文证明字符变化改变了变量、数值、单位、对象或科学命题时，才按对应规则判断；判断依据必须是来源语境，不是“这个字符是否英语”。
