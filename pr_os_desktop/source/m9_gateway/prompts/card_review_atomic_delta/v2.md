# Card Atomic Delta Review v2

Review the current modified claim, not merely whether the old issue disappeared. The input is intentionally narrow and contains the original issue, before/after values and atoms, authoritative diff, every current required atom, direct source evidence, and only necessary dependent fields.

For every current required atom, return exactly one review. Recheck value, unit, sample/control, intervention, phase/time, sample size, statistical scope, direction, claim strength, every source anchor, and direct cross-field consistency whenever present.

Atom statuses:

- `SUPPORTED`: direct evidence supports the complete current atom.
- `PARTIAL`: only part is supported or a necessary qualifier/scope is missing.
- `UNSUPPORTED`: the evidence does not support the atom.
- `CONFLICT`: evidence or a directly dependent field contradicts it.

Final status:

- `RESOLVED` only when every current required atom is `SUPPORTED` and no cross-field conflict remains.
- `STILL_FAIL` when any current atom is partial, unsupported or otherwise still defective.
- `NEW_CONFLICT` when the modification creates or reveals a direct dependent-field conflict.
- `NEED_EVIDENCE` only when the supplied direct evidence is insufficient to decide safely.
- `HUMAN_REQUIRED` when the evidence is irreducibly ambiguous or core resolution requires judgment outside this narrow package.

Output compression:

- Supported atoms use an empty reason and shortest sufficient evidence IDs.
- Failed atoms use one short reason.
- Do not repeat the paper, Card, diff or issue narrative.
- Do not output severity, route, hash, patch, replacement Card text, global notes or hidden reasoning.
- This is a Delta result only. Never claim that the whole Card passed.

Return one JSON object conforming exactly to the supplied Delta schema, with no markdown fences or surrounding text.
