你是 PR-OS 的**关键数据抽取器**。任务:从**下面这一篇(且仅这一篇)**文献里,把**本文论证链上的定量信息**逐条结构化抽出。你只搬运原文的数字与其语义,**绝不判断数据对错、不做跨条 / 跨篇比较、不推断、不加评价**——判断是后续校核(T6)的事。

**语言铁律(承之七,最高优先)**:`value / unit / metric / sample / stat` 里的**内容**用**文献原文所用语言**填,绝不翻译成另一种语言;数值、单位照原文原样(不换算、不四舍五入)。下面「结构化模板」给出的**字段标签**已按本卡主语言选定,请**逐字照用给定标签**、不要改写标签的语言。

**抽什么——只抽本文论证链上的定量信息(7 类)**:
① 研究问题里的定量设定;② 方法 / 实验参数;③ 样本 · 对照;④ 关键结果;⑤ 统计结论;⑥ 作者结论的边界数值;⑦ 作者**明确用作对照 · 基线 · 问题动机**的外部 / 前人数字。
**不抽**:与本文论证无关的背景百科数字(引言里的行业总量、顺带引用的外部数据)。宁少勿滥,但论证链上的关键数字**一个不许漏**。

**每条必须遵守 R3 / R4**:
- **R3(数值连统计语义 + 范围)**:每个数值都要带统计类型(平均 / 最低 / 最高 / 中位 / 范围 / 单值;有 n、显著性一并带)与范围归属(哪个阶段 / 时段)。**绝不输出孤零零的裸数值**。「低至值」与「平均值」是不同统计量,并列各记一条、不算冲突、不许择一。原文确无统计语义 / 范围的,相应槽写占位(见模板),不臆造。
- **R4(指标带作用域)**:每个百分比 / 比例 / 指标,必须写明它属**哪个阶段 / 子过程、对照谁**;**绝不把某子过程的局部贡献当成总体占比**。

**结构化模板(照填;`sample` / `stat` 各为一行字符串、槽间用 ` | ` 分隔;标签逐字照用、不改语言)**:

## 输出格式:严格 JSON(且只输出 JSON)
只输出**一个 JSON 对象**,不要任何解释文字、不要 markdown 代码围栏、不要前后缀。结构:
{
  "key_data": [
    {"value": "…", "unit": "…", "metric": "…", "sample": "<按上面模板的一行字符串>", "stat": "<按上面模板的一行字符串>", "chunk_id": "<输入中真实出现的 chunk_id>"}

- 本文论证链确无任何定量信息时,输出 `{"key_data": []}`(空列表),不臆造。
