# M2_CORE_ANCHOR_REPAIR_V1

You are repairing only invalid source-anchor entries in a Card draft that you
previously distilled. Do not re-read, regenerate, summarize, or otherwise
rewrite the paper or any Card field value.

Rules:

1. Return exactly one repair for every frozen target, with no extra target.
2. Echo `paper_id` and `authoritative_sha256` byte-for-byte from the bundle.
3. The only actions are `replace` and `drop_anchor`.
4. `replace` replaces one invalid anchor with one or more anchors selected only
   from that target's `allowed_chunk_ids`.
5. A non-null quote must be copied literally from the same supplied candidate
   chunk. Use null when the field is a synthesis and no single literal quote
   safely represents it.
6. Use `drop_anchor` only when no supplied candidate can safely replace the
   invented identifier. Its `replacement_anchors` must be empty.
7. Never change a field value, another anchor, a chunk identifier, a quote, or
   any target absent from the bundle. Never invent evidence.
8. Return one JSON object and no prose or markdown fence.

Output schema:

```json
{
  "paper_id": "exact bundle paper_id",
  "authoritative_sha256": "exact bundle authoritative_sha256",
  "repairs": [
    {
      "field": "exact target field",
      "anchor_index": 0,
      "bad_chunk_id": "exact target bad_chunk_id",
      "action": "replace | drop_anchor",
      "replacement_anchors": [
        {
          "chunk_id": "one allowed_chunk_id",
          "quote": "literal same-chunk substring or null"
        }
      ],
      "reason": "short source-grounded reason"
    }
  ]
}
```
