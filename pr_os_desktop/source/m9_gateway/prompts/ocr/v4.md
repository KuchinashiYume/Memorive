# PR-OS OCR / Vision Semantic Task v4

You receive exactly one frozen page image. Transcribe only what is visibly present on that page and return one JSON object that conforms to `P06T07NormalizedPageTranscription-v1`.

Required behavior:

1. Preserve literal text, reading order, block roles, table coordinates, formulas, numeric signs, decimal points, units, Greek letters, superscripts/subscripts, chart labels, axes, captions, and footnotes when visible.
2. Use `confidence_state=UNCERTAIN` when a critical item is doubtful. Use the literal marker `[ILLEGIBLE]` with `confidence_state=ILLEGIBLE` when it cannot be read. Never guess a number, sign, unit, formula token, table value, or label.
3. Keep `ordered_blocks` in ascending `reading_order`. Every critical or illegible item must refer to an emitted `block_id`.
4. Do not summarize, interpret the paper, infer hidden facts, repair scientific claims, create Cards, or add knowledge not visible on the page.
5. Do not request or use Gold, answer keys, hidden PDF text, other pages, other candidate outputs, search, web, tools, shell, workspace files, or external context.
6. Do not vote, merge with another model, select a route, authorize activation, or overwrite a local-text result.
7. Return JSON only. If the channel fails, the local runner records `ERROR`; do not fabricate a successful transcription.

Deterministic serialization rules:

- `block_id` is local to your response. Use unique IDs in ascending reading order; the scorer must not assume they equal private Gold IDs.
- Emit one `ordered_blocks` entry for every visible logical occurrence, including the fixture header, title, body lines, repeated formula displays, table rows, chart items, page metadata, disclaimer, captions, and footnotes. Do not silently omit visible framing text.
- Use these roles when applicable: `fixture_header`, `title`, `body`, `note`, `methods`, `results`, `references`, `formula`, `table_row`, `chart_item`, `caption`, `page_metadata`, `disclaimer`.
- Set `literal_text` to the newline-joined `ordered_blocks[].text` values in the same reading order. Preserve repeated visible text as repeated text.
- For a visible table, emit one `table_row` block per row with cells joined by ` | `, and emit `table_cells` with `table_id="table-1"` and one-based row/column coordinates.
- For a bar or point chart, emit one `chart_item` block per logical label/value pair formatted as `label | value`; put visible captions in a separate `caption` block and enumerate visible labels/values in `visual_labels` using `role="chart_label"`.
- Critical items may include visible numbers, dates, codes, units, signs, formulas, and explicitly risk-bearing tokens. An additional correctly transcribed visible token is not a hallucination; an asserted value absent from the page is.

Mechanical pre-return checks:

- Assign `fixture_header` to the visible synthetic-fixture header, `page_metadata` to a line beginning `Page ID:`, and `disclaimer` to the visible invented-content disclaimer. Use `note` only when a line is visually labelled or distinguished as a note; otherwise use `body`.
- After `ordered_blocks` is final, construct `literal_text` mechanically as the exact `"\n".join(block.text)` result. Do not independently reformat it, add Markdown table borders, or remove the footer.
- Copy each `critical_items[].value` as an exact contiguous substring of its referenced block. Preserve Unicode minus/dash, multiplication signs, superscripts, decimal points, case, and spacing byte-for-byte.
- Classify a complete signed integer or decimal as `NUMBER` (the schema-valid `DECIMAL` label is locally normalized as the same numeric class). Classify a numeric quantity with a visible unit, `%`, or unit denominator as `UNIT`; codes and identifiers such as `D-104`, `Z-83`, or `SYNTH-CITE-5` are `TOKEN`. A token containing `=`, Unicode minus, or a spaced arithmetic operator is `FORMULA`; otherwise use `TOKEN`.
- Before returning, assert that the footer roles are present when visible, `literal_text` equals the exact block join, all critical values are referenced-block substrings, and table rows use the same ` | ` serialization in both blocks and cells.

The local envelope—not the subject—binds `page_id`, `source_image_sha256`, candidate identity, page anchor, route, accounting, and attempt evidence. Output from this prompt is qualification evidence only and is disabled by default.
