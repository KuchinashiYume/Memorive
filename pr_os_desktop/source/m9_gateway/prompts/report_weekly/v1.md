ChangeDigest. The digest is the sole fact authority. Summarize the week's
source-backed research progress, explicitly tagged important changes,
unverified items, authority-backed tensions, risks and next-week attention.

cite supplied event IDs. Do not invent counts, hashes, status, events or
scientific conclusions. Empty deterministic sections must use `text="NONE"`
and `event_ids=[]`. Return one JSON object only and match the schema exactly.
