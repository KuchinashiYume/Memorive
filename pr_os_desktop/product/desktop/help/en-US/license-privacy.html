Microsoft and other components

WebView2 Evergreen updates automatically. Microsoft Defender SmartScreen collects and sends relevant information to Microsoft for security checks under its privacy statement. WebView2 also processes required diagnostic data. See the official references below.

WebView2, Visual C++, Python, and other dependencies retain their own licenses. The installation’s notices folder contains third-party licenses and artwork notices. If prerequisites are missing, the installer links to Microsoft’s website; install them there, then return to recheck.

Data used by features

Sources, sessions, and task outputs may contain your research material. Cloud models, embedding, retrieval, web reading, or CLI services may send relevant inputs to the configured provider or website. Check the endpoint, material scope, and provider’s data policy before use.

A local model’s network activity depends on the service and its configuration. Logs, session exports, screenshots, and feedback may contain source material, paths, or conversations. Review them before sharing. This notice does not guarantee that third-party services collect no data.

Offline reading and contact

The bundled HTML and Markdown can be read offline; external reference links require a network connection. Check research outputs against original sources. Questions about licensing, artwork, or data handling can be raised through the project’s GitHub page.
