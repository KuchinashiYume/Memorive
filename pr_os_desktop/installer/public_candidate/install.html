检查结果

需要补充 1 项
需要 Microsoft WebView2 与 Visual C++ v14 x64；其余程序环境由安装包自带。

从 Microsoft 官方来源安装缺少的组件，然后点击“重新检查”。

查看运行环境说明
安装包自带Memorive 核心、私有 CPython 与依赖、本地 UI、卸载程序。
系统运行库需要 WebView2、.NET Framework 4.8 和 Visual C++ v14 x64；缺少时从 Microsoft 官网准备。
无需准备Git、系统 Python、Node.js/npm、Rust、SDK、Ollama 和各家 CLI。
